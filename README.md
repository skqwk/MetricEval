### Проект генерации данных, моделирования алгоритмов планирования и оценки эмпирических метрик

### Структура

- dataset-generator - Python-модуль, выполняющий генерацию датасетов;
- scheduler-sandbox - Java-модуль, реализующий алгоритмы планирования и среду имитационного моделирования;
- notebooks - Jupyter-блокноты, для визуализации результатов экспериментов.


### Полезные команды

Запуск Jupyter Notebook (вместо `"C:\work\academic\metric-eval"` указать директорию, куда был склонирован проект)
```bash
python -m notebook --notebook-dir "C:\work\academic\metric-eval"
```

Удалить все результаты запусков, кроме исходного набора данных
```bash
find . -type f -name "*.csv" ! -name "dataset.csv" -delete
```
