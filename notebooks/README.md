# notebooks

Блокноты для визуализации результатов.

- `сustom_validation_notebook.ipynb` - основной цикл эксперимента с проверкой точности;
- `has_notebook.ipynb` - по адаптивному алгоритму;
- `util.ipynb` - вспомогательный блокнот.

Исходные данные можно сгенерировать самостоятельно либо скачать из раздела `Releases`.
